# Skill: Frontend Feature

## Read first

- `.ai/rules/frontend.md`
- `.ai/rules/api.md`

## Procedure

1. Define user flow.
2. Identify API contract.
3. Build focused components.
4. Implement loading/error/success states.
5. Handle authentication/ownership through backend.
6. Prevent duplicate expensive actions.
7. Add tests where appropriate.
8. Check responsive behavior.
