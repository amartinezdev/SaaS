# Product Skill: Listing Generator

## Purpose

Generate a publishable 3D-model listing from trusted/observed model information.

## Inputs

- model image/reference
- optional creator notes
- language
- platform
- creator style profile

## Rules

- Do not invent technical facts.
- Prefer observable characteristics.
- Use relevant keywords naturally.
- Avoid keyword stuffing.
- Follow platform limits.
- Respect creator style.

## Output

Structured:

- title
- description
- tags
- keywords
- category

## Validation

Run schema, business and platform validation before final output.
