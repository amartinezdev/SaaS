# Image Generation

Image generation creates promotional assets based on the creator's model/reference image.

Initial image types:

- HERO
- LIFESTYLE
- CLOSE_UP
- DESK_SETUP
- PROMOTIONAL

## Plan mapping

FREE:
free/open-source image provider after infrastructure validation.

CREATOR:
Gemini 2.5 image model.

PRO:
Gemini 3 Pro image model.

## Safety/accuracy

The generated image should preserve the identity and important characteristics of the model as much
as the provider allows.

Do not represent generated environments as factual product properties.

Store generation metadata and prompt version.
