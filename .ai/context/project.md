# Project Context

## Product

3D Listing AI helps 3D creators turn a model into a publishable commercial listing.

Primary input for MVP:

- model image/render

Future inputs:

- STL
- model metadata
- creator-provided notes
- previous listings

## Core outputs

- title
- description
- tags
- keywords
- category
- promotional images

Future outputs:

- platform-specific listings
- social posts
- video concepts
- bulk exports
- direct publishing integrations

## Target user

Creators who publish 3D-printable models on platforms such as MakerWorld, Printables,
Thingiverse and Cults3D.

## Core value proposition

Reduce repetitive listing preparation while improving presentation quality.

## Product principle

The product is not an AI demo. It is a workflow tool whose primary value is saved time.
