# Glossary

## Model

A creator's 3D-printable model.

## Listing

The commercial/publishing metadata for a model: title, description, tags, keywords and category.

## Generation

A single AI operation.

## Image generation

AI creation of a promotional image based on the model/reference image.

## Credit

A unit of usage for cost-bearing AI operations.

## Creator

The paid plan using the standard paid image model.

## Pro

The higher paid plan using the premium image model.

## Skill

A reusable procedural instruction set that tells an AI how to perform a specific development task.

## Style profile

Structured creator preferences used to shape AI-generated listings.
