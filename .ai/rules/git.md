# Git Rules

- Keep commits focused.
- Use descriptive commit messages.
- Do not commit secrets.
- Do not commit generated user files.
- Do not mix unrelated refactors with feature work.
- Run tests before committing substantial changes.

Suggested style:

```text
feat: add listing generation
fix: prevent duplicate credit deduction
refactor: isolate image provider adapter
test: cover creator credit limits
docs: update image generation architecture
```
